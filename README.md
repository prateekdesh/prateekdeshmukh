# prateekdeshmukh.com

Prateek's personal index: selected engineering work, writing, side projects,
and the things he keeps coming back to.

## Development

```sh
npm install
npm run dev
```

The site is built with SvelteKit. The design rationale and content rules live in
[`DESIGN.md`](./DESIGN.md).

## Production build

```sh
npm run build
npm run preview
```
